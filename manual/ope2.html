Create ENDF-6 Data From File (Cross Section)

read (read cross sections from file)

   read  MFnumber MTnumber "file_name" [offset]

DeCE can read cross section data from external data files, and store the data into a specified MF,MT section. In the current version, the MF number should be 1 (number of fission neutrons) or 3 (cross sections). The file name must be quoted by the quotation marks.

The data in the external data file are in the table format, like

 ...(snip)...
 8.000000e-01 4.944550e+03 4.656816e+01
 9.000000e-01 4.735559e+03 3.920111e+01
 1.000000e+00 4.550877e+03 3.409828e+01

where the energies are in MeV, and the cross sections in milli-barns as a default. When offset is not given, DeCE reads the first column as the energy, and the second column as the cross section. When offset = 2 is specified for example, the second column data will be skipped and the third column data are copied.

The unit of the external data can be changed by the option ReadXdataConversion and ReadYdataConversion.

The read command automatically inserts the lowest energy point (10-5 eV) and the thermal energy point (0.0253 eV), which are probably zero, unless no resonance parameters are given.

Often the energy range given in the file does not match the ENDF-6 file. For example, the lower region may overlap with the resonance range where the cross sections in MF=3 should be zero (or background cross sections are given). DeCE tries to adjust the energy boundary at the upper side of the resonance region.

In this case, the resonance region goes up to 100 keV, and therefore the data below 100 keV are skipped. Ocassionally, though quite rare, DeCE cannot determine the correct resonance upper boundary. Users should be aware of this.

For the threshold reactions, such as (n,p) when its Q-vale is negative, DeCE calculates the threshold energy and inserts it automatically. However, this is not the case for the inelastic scattering (MT=51-91), and the charged particle emissions where the residual nucleus is left in its discrete levels or continuum (MT=600--849). Because there is no simple way to infer the discrete level energies, users need to supply the excitation energies of the level in the first line. mergeread (read cross sections from file and merge with existing data)

   mergeread  MFnumber MTnumber "file_name" [offset]

When background cross sections are given in the resonance region, the read command may overwrite the background. mergeread replaces the cross sections above the resonance region only, and maintain the background cross section in the resonance region.

replaceread (read cross sections from file, ignore existing data and resonance range)

   replaceread  MFnumber MTnumber "file_name" [offset]

Existing data in MF,MT will be overwritten by the external data in the entire energy range. The lowest and thermal points are not produced be DeCE, so that these two points (at least the lowest energy) should be given in the external data file. Or, you can add these data points by addpoint.

multiread (read multiple cross section data from file)

   multiread  MFnumber MTstart MTlast "file_name"

DeCE reads all MT numbers from MTstart to MTlast from the same data file "file_name". Since an offset is not given in this operation, DeCE assumes that the data file includes the reactions in the following column order - Energy, Total, Elastic, Non-elastic, Capture, Inelastic, and Fission. For the particle production cross section cases - Energy, (x,n), (x,p), (x,alpha), (x,d), (x,t), (x,h), (x,2n), (x,np), (x,n alpha), (x,nd), (x,nt), (x,nh), (x,2p), (x,p alpha), (x,pd), (x,2alpha), (x,d alpha), (x,3n), (x,2np), (x,2n alpha), (x,np alpha), (x,n2p), (x,4n), (x,5n). For the partial inelastic scattering - Energy, elastic, 1st level, 2nd level, 3rd level ... and the last 40th column is the continuum inelastic.

multiread repeats the read in the range of MT numbers. To use mergeread and replaceread for multiple MT numbers, you have to do it one by one.

readradioactive (read radioactive isotope production cross sections from file)

   readradioactive  MFnumber MTnumber "file_name" [offset]

Similar to read, DeCE imports radioactive isotope production cross section data from external files. The data given in the file are cross sections. The compiled data depend on MFnumber. When MTnumber = 9 the provided cross sections will be converted into multiplicities, while cross section data will be stored when MTnumber = 10. When the data column option ofset is not given, DeCE will look for the proper data column number by the data given in the header part.

For the both MTnumber = 9 and 10 cases, a corresponding MF=8 section is created automatically.

Additional information of radioisotopes is required in the external data file in the header pat. For example, neutron-induced reactions on 89Y produces several radioactive isotoes. The inelastic scattering process may produce a meta-state 89mY at 909 keV, whose half-life is 16 sec. The neutron capture reaction also produces unstable ground 90gY and meta-state 90mY at 682 keV. The reuqired information is:

  • radioisotope identifier, ZA 1000 x Z + A = 39090 for capture, and 39088 for (n,2n)
  • excitation energy of the meta-state, Ex
  • outgoing particle counting string NNNNNN. The first letter is the number of neutrons, the second is for proton, third is the alpha-particle, deuteron, triton, and helium3. For example, NNNNNN = 000000 for the capture, 200000 for the (n,2n) reaction. This is used to locate the data column for a given MT number.

  • excited state number Nx counting from the first excited state; 682 keV level is the second excited state, so this number is 2.
  • half-life of the state T(1/2). For the stable states, T(1/2) = 0.0.

The total number of the meta-states is limited to two. One radioactive isotope data must be given by a triple column - ground state, first meta, and second meta. Always the ground state production must be given, even if this state is stable. If there is no second meta, Ex and Nx can be any unreadable text. However, T(1/2) should be zero to specify the data column will be skipped.

The ofset parameter is given for the triple-column. In the case below, ofset = 1 for the capture ZA = 39090, and ofset = 2 for the (n,2n) ZA = 39088. Since the excitation energy and the state number for the ground state are obvious, ZA and NNNNNN are given in their location. When ofset is not given, DeCE checks the outgoing particle counting to locate the proper column, like "000000" for the capture or "100000" for the inelastic scattering.
